# Lunchappen

Registrera frukost, lunch och middag på restaurang och följ utläggen per vecka, månad och år. Markera representation, annars räknas utlägget som personligt. Restaurangen kan fyllas i automatiskt utifrån din position (OpenStreetMap).

Installerbar webbapp (PWA): öppna sidan i Safari (iPhone) eller Chrome (Android) och välj **Lägg till på hemskärmen**. Datan sparas bara i telefonen.
